# Reel 008 — Weather

Four characters, four kinds of moving air: dust, tyre smoke, rain, and embers. The [Instagram film](https://www.instagram.com/cinematic_llm/) and its tutorial show how one still image became each seven-second shot.

## Use the resources

1. Read the [director map](prompts/0_director_map_all_four_clips.md) for the four-shot plan.
2. Use the [scene breakdown prompt](prompts/1_scene_breakdown_prompt_attach_a_pinterest_photo.txt) on a scene reference where the particles and light are clear. Use its output as scene notes, not as a face source.
3. Make a start frame in a fresh ChatGPT chat for [dust](prompts/2_start_frame_dust_attach_her_photo_her_angles_and_the_car.txt), [smoke](prompts/3_start_frame_smoke_attach_his_photo_his_angles_and_the_car.txt), [rain](prompts/4_start_frame_rain_attach_her_photo_and_her_angles.txt), or [embers](prompts/5_start_frame_embers_attach_his_photo_and_his_angles.txt). Attach the character identity image, their angle sheet, and the car where the prompt calls for it.
4. Use the matching Kling 3.0 prompt for [dust](prompts/6_kling_3_0_video_prompt_dust_start_image_only_7s.txt), [smoke](prompts/7_kling_3_0_video_prompt_smoke_start_image_only_7s.txt), [rain](prompts/8_kling_3_0_video_prompt_rain_start_image_only_7s.txt), or [embers](prompts/9_kling_3_0_video_prompt_embers_start_image_only_7s.txt). The tested setup was a seven-second, 9:16, standard 720p image-to-video clip on Higgsfield, with the matching start frame only and sound off.

The [four start frames](images/) and [twelve clip stills](stills/) are the original generated results. Each scene has a start, middle, and end still. No Pinterest reference photos are included.

## What happened in this test

All four Kling clips were kept from one take each, with no retries. The faces held through the shots. Rain beaded on skin and soaked hair; the firelight picked out the warrior's dented armour. The dust clip did not leave a visible finger mark on the bonnet, and the embers thinned after about a second. The smoke formed a heavy veil rather than a solid wall. The film's particle sounds were made in the edit, not generated by Kling.

The prompts here are the working resource copies. Two short generic phrases in the start-frame prompts were reworded for publication; those edits did not change the method. These outcomes describe this specific run, not a guarantee for another model or source image.
