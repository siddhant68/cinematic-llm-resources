# Cinematic LLM — free filmmaking resources

The images and exact prompts behind **Show Yourself**, a 35-second AI short film about Rudra Singh's last charge against a storm-born beast.

Start with [Reel 006](reel-006/README.md). The seven prompts are kept as individual text files so you can copy them without trying to read them from an Instagram slide. The full storyboards, five reference images, and every storyboard and angle-sheet panel are here too.

The [Cinematic Sequence Director skill](skills/cinematic-sequence-director/SKILL.md) is the directing playbook used to write the two video prompts. It fixes set geography, lighting, prop continuity, and camera choices across connected clips.

Created for [@cinematic_llm](https://www.instagram.com/cinematic_llm/). AI imagery is illustrative. Prompts describe the process used for this specific film; results will vary with models and reference images.
