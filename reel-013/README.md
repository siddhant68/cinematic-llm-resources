# Reel 013 — Genjutsu recast: the prompt template

A real fight, recast shot for shot with two original characters, using Higgsfield Genjutsu. The tutorial reel shows how the prompt is written; this folder is the working material. The Instagram film is "Trial by Combat" on [@cinematic_llm](https://www.instagram.com/cinematic_llm/).

## Use the resources

1. Read the [template and assets checklist](prompts/0_GENJUTSU_PROMPT_TEMPLATE_assets_checklist_and_template.md). It says what the video, the images and the prompt each decide, lists what to prepare, and gives a fill-in prompt.
2. Make each person's two images in a fresh ChatGPT chat from one photo of that person: a [standing turnaround sheet](prompts/1_character_sheet_fighter_1_standing_turnaround_attach_one_photo.txt) and a [six-expressions sheet](prompts/2_character_sheet_fighter_1_six_expressions_attach_one_photo.txt) for fighter 1, the same two for [fighter 2](prompts/3_character_sheet_fighter_2_standing_turnaround_attach_one_photo.txt) ([expressions](prompts/4_character_sheet_fighter_2_six_expressions_attach_one_photo.txt)).
3. Make the place with the [arena plate prompt](prompts/5_arena_plate_image_prompt.txt).
4. In Genjutsu, attach the video, then the images in the order the prompt numbers them: face, body, face, body, place. Use the matching working prompt: [clip 1](prompts/6_genjutsu_prompt_clip1_three_shots_portraits_then_wide.txt) (three shots), [clip 2](prompts/7_genjutsu_prompt_clip2_one_shot_corner_clinch.txt) (one shot), [clip 3](prompts/8_genjutsu_prompt_clip3_close_exchange_two_shots.txt) (two shots).

The [five attached images](images/) and [nine clip frames](stills/) (start, middle and end of each clip) are the original generated results. The source fight footage is not included.

## What happened in this test

Three Genjutsu clips, one take each, 720p, 112 credits (42 + 42 + 28). All three used the same five images: two sheets per fighter and the arena plate. One clip swapped who plays which fighter. The wide shot in clip 1 kept cameras in the crowd in both lower corners (see its end frame), although the prompt said "holding nothing". One fighter's cropped hair came out fuller in clip 3. Every clip keeps the source sound and repeats one frame about once a second. Two other jobs were flagged as protected characters and refunded, so both fighters are original characters. One earlier 480p test cost 18 credits and is not included.

These outcomes describe this run only, not a guarantee for another video, model version or set of images. The motion in the film comes from a real fight, Don Frye vs Yoshihiro Takayama at PRIDE 21 (2002).
