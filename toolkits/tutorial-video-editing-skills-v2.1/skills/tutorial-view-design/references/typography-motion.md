# Typography and motion boundary

`tutorial-motion-graphics` owns the copy hierarchy, animation system, reusable templates, diagrams, section openers, memory anchors, and recap.

`tutorial-view-design` owns:

- where graphics can safely appear
- relationship to host, B-roll, UI, captions, and end-screen zones
- whether a full-frame graphic or overlay is appropriate
- screen zoom/crop and callout target
- visual entry/exit bridge

Do not let both skills independently design the same treatment. The motion-graphics plan is authoritative for the graphic; the style profile is authoritative for safe placement and visual consistency.
