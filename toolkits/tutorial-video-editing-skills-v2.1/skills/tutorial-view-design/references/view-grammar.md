# View grammar

## View selection table

| Viewer need | Default view | Common secondary view |
|---|---|---|
| trust, interpretation, emotion | FACE | HOST_OVER_CONTENT |
| physical workflow or orientation | DESK | FACE |
| exact interface instruction | SCREEN | HOST_OVER_CONTENT |
| result, failure, proof | BROLL | HOST_OVER_CONTENT |
| before/after or alternatives | COMPARE | FACE reaction |
| abstract process or sequence | GRAPHIC | HOST_OVER_CONTENT |
| reading or reflection | HOLD | quiet FACE or SCREEN |

## Presenter presence

A long absence can weaken trust, but a persistent PIP can shrink the content. Plan the host as a narrative resource, not a permanent watermark.

Return to FACE after proof when interpretation matters. Keep HOST_OVER_CONTENT when reaction, authority, or relationship to the content matters. Remove the host when the viewer must inspect detail.

## Cut continuity

A view change should preserve one or more:

- continuous dialogue
- room tone or natural sound
- motion direction
- eyeline
- hand or cursor action
- screen geography
- color/shape relationship
- unresolved question

## Side-camera use

The side camera is strongest when it reveals embodied work, environment, or a transition into action. It is weak when used as a random cutaway or when the laptop screen is too small to teach from.

## Screen recording

Crop only when the context remains understandable. Use cursor highlighting, callouts, or measured zoom rather than a constantly wandering digital camera.

## B-roll

Use only approved B-roll plan items. A visual should add information, evidence, emotion, orientation, comparison, payoff, or breathing room.
