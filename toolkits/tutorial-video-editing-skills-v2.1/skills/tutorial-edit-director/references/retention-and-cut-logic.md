# Retention and cut logic

## Retention is a sequence of fulfilled expectations

Plan attention around:

- a credible opening promise
- visible progress
- questions the viewer wants answered
- evidence that arrives when promised
- changes in information mode
- moments of compression and breathing room
- a clear conclusion

Effects can support those functions but cannot replace them.

## Cut decision order

At every proposed edit point, ask:

1. Did the information source change?
2. Does the new view improve comprehension?
3. Can audio continue across the cut?
4. Is there motion, gaze, shape, color, or screen geography to match?
5. Does the viewer need a hold instead?
6. Is a transition effect actually communicating time, space, comparison, or section structure?

Use the first simple solution that works.

## J-cuts

Start the next beat's audio before its picture when it prepares the viewer for a new idea, location, tool, or section. Keep the overlap short enough that source identity is not confusing.

## L-cuts

Let the current speaker continue over proof, screen demonstration, B-roll, or a reaction. Use this as the default way to keep the explanation continuous while changing visuals.

## Jump-cut repair order

1. Preserve the natural cut when performance and framing tolerate it.
2. Use an audio crossfade and room tone.
3. Cut to meaningful screen/B-roll/proof.
4. Use the side camera if it adds context.
5. Use a deliberate crop or punch-in only when resolution supports it.
6. Use a graphic only when it also helps comprehension.

Do not hide every jump cut with random B-roll.

## Pattern interrupts

Use at natural teaching turns, not a fixed timer. Examples:

- remove music before a critical rule
- replace talking head with proof
- move from desk orientation to exact screen view
- reveal a comparison
- show a concise section header
- return to the host for interpretation
- use silence before the result

## Opening

The first 30 seconds should align with the title/thumbnail promise, demonstrate relevance, and make the next question obvious. Prefer actual result footage or a clear failure/result contrast over a generic channel intro.

## Ending

Resolve the opening promise, recap the section path, state the final rule, and leave clean visual space for the end screen. Do not introduce an unrelated final topic.
