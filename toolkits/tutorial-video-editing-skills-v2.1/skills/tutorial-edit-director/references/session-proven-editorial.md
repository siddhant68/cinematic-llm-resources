# Session-proven editorial decisions

- After every ripple removal, search the nearby final transcript for repeated two-to-six-word phrases, then listen across the splice. Waveform closure alone missed repeated introductions and repeated claims.
- When a section card feels rushed, hold picture and pause dialogue together. A 0.75-second complete A/V hold worked in the completed episode; tune the value to the copy.
- Late picture-only work is conform work: preserve the approved duration map, dialogue cuts, holds, caption timing, ambience, music, and SFX, then rebuild deterministically over the replacement picture.
- A plurality-to-payoff opening can use a brief multi-shot grid followed by one full-screen hero example exactly when the speaker names it.
- State the central workflow thesis early and return to it in the closing so the episode reads as one argument.
