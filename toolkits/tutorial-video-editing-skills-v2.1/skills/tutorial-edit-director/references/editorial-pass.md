# Editorial pass

## Pass 1: Source truth

Inventory and probe originals. Verify sync. Identify generated, downloaded, proxy, and intermediate files. Record rights and quality risks.

## Pass 2: Transcript alignment

Align full script, teleprompter script, transcript, and waveforms. Detect false starts, paragraph restarts, missing lines, deliberate repetition, and unscripted useful material. Create `retake_decisions.json` with confidence and handles.

## Pass 3: Radio cut

Build one continuous production-dialogue spine. Repair edits with room tone and crossfades. Remove accidental silence but preserve expressive pauses.

## Pass 4: Section architecture

Name sections by viewer outcome. Define entry question, proof, memory anchors, payoff, and bridge.

## Pass 5: Visual intent

Assign the information role before the source: trust, demonstration, evidence, orientation, comparison, reaction, graphic explanation, or hold.

## Pass 6: Specialist planning

Run B-roll, view/composite, motion-graphics, and audio plans. Reconcile collisions before editing.

## Pass 7: Look development

Build one representative sample. Review all modes together. Lock only what survives desktop and phone-size inspection.

## Pass 8: Section-by-section build

Apply the approved grammar. Read back changes and render representative frames after each section.

## Pass 9: Finish and QC

Finish composite, graphics, color, audio, captions, and export. Run QC on the rendered master and close blockers/majors.
