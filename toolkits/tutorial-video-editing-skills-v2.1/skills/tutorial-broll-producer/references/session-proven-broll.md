# Session-proven B-roll decisions

- Reuse B-roll when narration deliberately revisits the same evidence; link every repeat to the repeated claim.
- Cut adjacent B-roll directly when it supports consecutive clauses. A short A-roll flash is an error unless the presenter reaction is the point.
- If a generated clip has one defective interval and appears repeatedly, repair/exclude that source range once and use the clean derivative everywhere. Recheck every occurrence.
- Watch generated clips at normal speed; stills can hide morphing limbs, object intersections, furniture phasing, unstable text, and geometry drift.
- Preserve source aspect ratio when no upscale exists; a clean 4:3 presentation is better than stretching evidence.
- When the opening claim is “these came from separate generations,” a short 2x2 grid can establish plurality, followed by one full-screen hero payoff when the narration names the decisive example.
