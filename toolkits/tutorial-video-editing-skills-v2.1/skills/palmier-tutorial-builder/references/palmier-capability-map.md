# Palmier capability map

Confirm every item against the live Agent/MCP tools before use.

Palmier's current documentation covers:

- multicam synchronization and source roles
- face/screen layouts including PIP and split views
- transcript-aware editing
- text and captions
- fades, keyframes, audio and timeline operations
- color/effects
- basic and tracked masks including Magic Mask
- chroma key
- image/video/audio generation
- FCPXML/XML export

Capability does not determine workflow responsibility. For this bundle:

- Palmier may do synchronization, transcript cleanup, and rough switching.
- Resolve owns final masks, compositing, typography, motion graphics, audio automation, color, and delivery.
- Higgsfield/LTX own generated asset creation after planning and approval.

Use live tool schemas as the execution contract. When a documented capability is absent from the active session, report it as unavailable.
