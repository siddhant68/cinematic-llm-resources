# Motion language

## Default motion families

- `fade_position`: short opacity plus small directional move
- `mask_reveal`: reveal along a line or shape that already belongs to the layout
- `line_draw`: diagrams, brackets, and UI callouts
- `progressive_build`: step lists and node flows
- `graphic_match`: carry one shape, line, or position into the next visual
- `static_hold`: use when movement would compete with reading

## Speed classes at 30 fps

Use as starting points, then scale for the project frame rate:

- micro: 5-8 frames
- standard: 8-14 frames
- structural: 12-24 frames

Readable hold begins after the entrance completes. Do not count animation time as reading time.

## Easing

Use one approved ease-out family for entrances and ease-in family for exits. Avoid overshoot unless a playful channel identity explicitly requires it.

## Direction

Motion direction should follow information flow, screen geography, or a recurring section grammar. Do not alternate directions randomly.

## Zooms

Use zooms to improve screen legibility or reveal a spatial relationship. Begin before the viewer needs the detail, settle while the detail is discussed, and return only when the wider context matters. Do not punch in on the host every few sentences.

## Pattern interrupts

A pattern interrupt may be:

- changing from host to proof
- removing music for a critical rule
- switching to a full-frame result
- revealing a diagram
- using silence before a payoff
- a concise section card

It does not need to be a glitch, whip, or impact.
