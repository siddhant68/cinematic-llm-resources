# Recommended Resolve track template

Adapt when required but keep semantic roles predictable.

## Video

| Track | Role |
|---|---|
| V1 | synchronized face/desk program base |
| V2 | full-screen screen capture, B-roll, or comparison base |
| V3 | host PIP or isolated presenter cutout |
| V4 | holdout masks, arrows, highlights, and UI callouts |
| V5 | accessibility captions |
| V6 | section titles, claims, step graphics, and recaps |
| V7 | shared adjustment clips only when documented |

## Audio

| Track | Role |
|---|---|
| A1 | continuous production dialogue spine |
| A2 | room tone and meaningful natural sound |
| A3 | music |
| A4 | SFX |
| A5 | alternate or scratch reference, muted |

## Rules

- Do not duplicate audible dialogue across camera tracks.
- Keep captions separate from structural graphics.
- Put host overlays on a predictable track for collision checks.
- Use adjustment clips sparingly; hidden global effects make debugging difficult.
- Name timelines, compound clips, Fusion comps, and renders deterministically.
