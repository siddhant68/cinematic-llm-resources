# End-to-end operating workflow

1. Complete and validate `EPISODE_BRIEF.json`.
2. When no passing setup report exists, install DaVinci Resolve and approved prerequisites if absent, launch and verify a disposable project/render, then configure and test the MCP.
3. Inventory, probe, hash, and synchronize original sources.
4. Align full script, teleprompter script, transcript, and recorded takes.
5. Build the clean dialogue story cut and section/retention map.
6. Run the B-roll producer: owned assets first, licensed-source research second, motion graphics third, generated assets only for justified gaps.
7. Run view design and mask-first composite planning.
8. Run motion-graphics planning for section openers, memory anchors, screen callouts, comparisons, and final recap.
9. Run music/SFX/tempo planning and rights checks.
10. Present the consolidated planning package and exact Higgsfield spend estimate.
11. Build and review a 60-90 second look-development sample.
12. Build the full episode one section at a time in Resolve.
13. Finish masks, Fusion graphics, Fairlight automation, color, captions, and master render.
14. Run rendered-media QC and close all blockers/majors.
15. Hand the master, captions, chapters, rights/provenance files, and thumbnails to the YouTube bundle.

Palmier is optional at step 3-5 only. When used, export FCPXML early and relink original media in Resolve. Never use a Palmier delivery render as the master A-roll source.
