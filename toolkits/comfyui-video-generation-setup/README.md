# Cinema — local AI video knowledge base

Everything learned building a local LTX-2.5 video pipeline on an M5 Pro Mac:
skills, documentation, scripts, patches and example workflows.

**This folder is a consolidated snapshot of one Mac setup.** It is a reference for adapting a local pipeline, not a one-command installer. The *live* installs on the original machine are elsewhere:

| What | Lives at | This repo has |
|---|---|---|
| Skills Claude actually loads | `~/Developer/video-pipeline/skills/` (symlinked into `~/.claude/skills/`) | a copy in `Skills/` |
| ComfyUI + the patch | `~/Documents/Applications/ComfyUI/` | scripts, patch and docs |
| The 104 GB model library | `~/Documents/Applications/comfy-models/` | nothing, too large |

Edit the live copies, not this snapshot, or the two will drift.

The public copy replaces the original user's home path with `~` in documentation. Set `COMFY_ROOT` and edit `patches/extra_model_paths.yaml.reference` for your own installation. Some commands refer to a sibling `../pipeline/` directory that is outside this toolkit; those commands require the corresponding scripts from your own setup. Model weights, credentials, caches, and generated media are not included.

## Using it from a new Claude session

The skills auto-trigger. You do not name them.

```
Generate a 6 second video of <idea>. Reference image at <path> on the first frame.
```

That is enough. It will start ComfyUI, write the prompt, generate, verify the
output is not black, and hand you the clip.

Read `docs/how-to-generate-video.md` for every parameter you can pass.

**Finishing stages**

`--interpolate N` runs RIFE and multiplies fps to match, so duration and audio
sync do not change; it buys smoothness, not slow motion. `--upscale N` runs a 4x
model and resamples down to N times the render size.

```bash
# a vertical reel: render small, deliver exactly 1080x1920 at 48fps
./ltxgen.py --prompt "..." --res 576x1024 --seconds 5 \
            --ref open.png:0 --ref close.png:-1 \
            --interpolate 2 --upscale 1.875 --out reel_01
```

The upscale runs **before** interpolation and in 16-frame chunks. Both matter: the
upscaler is the expensive stage so it should see the original frame count, and it
allocates the whole output batch at once — 241 frames at 4x is a 27 GB tensor,
which put a 48 GB machine into 16 GB of swap and never finished. Lower
`--upscale-chunk` if you still see swap.

**Two rules that bite if ignored:**

1. Launch ComfyUI only via `start.sh`. It carries `--use-pytorch-cross-attention`.
   Without that flag the model returns NaN at some seeds and writes a completely
   black mp4 while reporting success.
2. Re-apply `patches/mps-int8-emulate.patch` after any ComfyUI update. `git pull`
   removes it and the model silently drops to CPU at roughly a tenth of the speed.
3. The default negative prompt **is never evaluated**. Both CFG values are 1.0 and
   ComfyUI skips the unconditional pass at that scale. Fix artifacts in the
   positive prompt; see `Skills/ltx-video/references/parameters.md`.

## Measured costs, M5 Pro 48 GB

| Clip | Draft (1 stage, 864x480) | Final (2 stage, 1280x704) |
|---|---|---|
| 4 s | ~2.5 min | ~8 min |
| 6 s | ~4 min | ~12 min |
| 8 s | ~5 min | ~16 min |

Memory is never the constraint (peak ~33 GB of 48). Time is. Restart ComfyUI
before every render at 0.7 MP and above.

## Keeping the copies in sync

There are seven copies of `ltxgen.py` on this machine and none of them are
symlinks. That is how the image generator kept pointing at the wrong model for
weeks after the browser workflow had been fixed. After editing anything in
`scripts/`:

```bash
../pipeline/sync.sh
```

It copies out to ComfyUI, `~/.claude/skills`, `~/Developer/video-pipeline` and the
in-repo snapshots, then prints checksums so you can see they match.

## Connected to image generation

`../pipeline/scenegen.py` runs a character reference through keyframes into
clips in one command, holding the same reference across every shot and generating
each still at the clip's own resolution.
