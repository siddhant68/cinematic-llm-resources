# YouTube Studio checklist

## Identity and checks

- correct channel and video ID
- expected duration and primary thumbnail
- HD processing complete
- copyright checks and restrictions reviewed
- monetization/ad suitability reviewed when applicable

## Details

- approved title and description
- manual chapters visible
- primary thumbnail correct
- playlist, language, category, audience, and disclosures correct
- promised resources and links work

## Video elements

- reviewed caption track
- cards have timecode and purpose
- end screen uses the final eligible range
- no collision with captions, presenter, proof, or CTA

## Packaging experiment

- eligibility confirmed
- title-only, thumbnail-only, or paired mode recorded
- two or three materially different variants
- test start state verified
- no manual packaging change during an active test without a recorded reason

## Comments and launch support

- approved top-level comment posted
- visible pin verified after comments become available
- community post created/scheduled only when it adds value

## Final release

- desktop and mobile watch page reviewed
- TV/large-screen preview reviewed when practical
- exact publish/schedule time and timezone confirmed
- viewer-facing page rechecked after visibility changes
- release record saved and handed to launch optimizer
