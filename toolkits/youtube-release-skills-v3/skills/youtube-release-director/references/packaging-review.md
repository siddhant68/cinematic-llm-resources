# Packaging review

## Title and thumbnail pair test

For each variant, answer:

- What does the viewer think they will receive?
- What proof in the video supports the promise?
- Is the title understandable without the thumbnail?
- Does the thumbnail add information instead of repeating the title?
- Can the focal idea be understood at phone size?
- Is any expression, result, comparison, or UI screenshot misleading?

Reject variants that use vague hype, unreadable collage layouts, or a result not reached in the video.

## First-minute alignment

Watch the first minute with the packaging visible. The hook should acknowledge the same problem and begin providing evidence. A strong thumbnail cannot compensate for a mismatched opening.

## Description review

Check links, credits, chapter labels, resource claims, affiliate disclosures, synthetic-media disclosure language, and playlist references. Keep the first visible lines useful without expanding the description.

## Caption review

Spot-check the hook, every technical term, names, acronyms, code, section transitions, and the close. Confirm captions are synchronized to the exported master rather than a pre-edit transcript.
