## 1. Title strategy

### Search-led

Use when the viewer has an explicit problem. Name the task, tool, or outcome clearly. Put the important phrase early and preserve natural language.

### Browse-led

Use when the video offers a surprising result, experiment, or strong pain point. Curiosity must remain understandable without insider context.

### Proof-led

Use when the creator can show an output, before/after, failure, benchmark, or finished system. Make the proof concrete rather than using generic superlatives.

A strong title is accurate, concise, and useful even when the thumbnail is not visible.

## 2. Title scoring

Score 1-5 on:

- clarity
- specificity
- audience relevance
- credibility
- distinctiveness
- first-minute alignment
- mobile truncation resilience
- compatibility with the paired thumbnail

Reject titles that require ALL CAPS, excessive punctuation, or unexplained jargon to feel interesting.

## 3. Description structure

The first visible lines should add context or value, not boilerplate. Use the rest for chapters, resources, playlists, credits, and disclosures.

A useful template:

```text
[One- or two-line continuation of the promise.]
[What the viewer will understand or build.]

RESOURCE
[Promised download or related asset]

CHAPTERS
00:00 ...

WATCH NEXT
[Relevant video or playlist]

ABOUT
[Brief creator/channel context]

CREDITS & DISCLOSURES
[Required attribution, affiliates, altered/synthetic disclosure]
```

## 4. Pinned comments

Good pinned comments do one job:

- deliver a resource
- ask a thoughtful question
- correct or clarify
- route to the next relevant video

Examples of useful structures:

```text
The full workflow/skill file is here: [link]. Which part of your current edit breaks first: story cut, B-roll, or audio?
```

```text
One clarification after publishing: [specific correction]. I have added the corrected step at [resource/chapter].
```

Avoid “Like, subscribe, and comment below” as the main content.

## 5. Community posts

A launch post should add a new reason to care:

- one before/after image
- a poll about the audience's current pain
- one surprising failure from production
- a concise lesson and the video link

Do not duplicate the title and description verbatim.

## 6. Metadata anti-patterns

- keyword-stuffed paragraphs
- more than 60 hashtags
- unrelated trending phrases
- misleading title/thumbnail mismatch
- tiny collage thumbnails
- title and thumbnail repeating identical wording
- generic tags treated as a growth strategy
- chapter names that do not match the visible structure
