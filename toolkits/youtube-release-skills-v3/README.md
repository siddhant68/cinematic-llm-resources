# YouTube release skills v3

Use this bundle after the video master has passed editing/QC. It turns the final video and channel context into a complete release package rather than merely uploading a file.

## Included capabilities

- analyze the final master, opening promise, target viewer, and continuation path
- create up to three materially different title-thumbnail hypotheses
- construct actual thumbnail masters, API-safe files, and phone-size previews
- write the description, chapters, captions, resource/credit sections, and disclosures
- write the pinned comment and optional community post
- plan playlists, cards, end screen, subscriber notification, schedule, monetization, and audience settings
- validate rights and release gates
- upload the video private first through the official API and verify readback
- complete Studio checks, native title/thumbnail testing, comment pinning, and release
- prepare 24-hour, 72-hour, and 7-day analytics reviews

The workflow improves packaging and launch discipline but cannot guarantee that a video becomes viral or “catches on.”

## Skills

- `youtube-release-director`
- `youtube-thumbnail-builder`
- `youtube-api-publisher`
- `youtube-studio-finisher`
- `youtube-launch-optimizer`

Install individual archives from `installable/<skill-name>/skill.zip` or expose the editable folders under `skills/`.

## Inputs

1. QC-passed final master.
2. Final captions and transcript/script.
3. Chapter timecodes or permission to derive them from the final master.
4. Target viewer, problem, outcome, strongest proof, and opening promise.
5. Channel positioning, playlist context, relevant prior videos, and next-viewer destination.
6. Owned portraits, screenshots, result frames, and brand references for thumbnails.
7. Resource links, affiliate links, credits, and disclosures.
8. Made-for-kids, paid-promotion, synthetic-media, monetization, notification, visibility, schedule, and timezone decisions.
9. Separate thumbnail-generation budget.
10. Explicit approvals for packaging, private upload, and public release.

Copy `YOUTUBE_RELEASE_INPUT_TEMPLATE.json` to `YOUTUBE_RELEASE_INPUT.json`, fill it in, and keep account secrets under a local `secure/` directory outside this bundle.

## Start

Attach the completed input file, channel profile, master, captions, transcript, thumbnail sources, provenance records, and this extracted bundle. Paste `PASTE_THIS_FOR_YOUTUBE_RELEASE.md` into the fresh session.
