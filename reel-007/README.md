# Reel 007 — Out

A powder-blue rally coupe crosses a broken bridge at golden hour. The jump slows down; stones hang in the air; the passenger's held breath becomes a laugh. The landing cuts back to real speed.

## Make it in order

1. In a fresh ChatGPT chat, attach one Pinterest photo and run [the visual breakdown prompt](prompts/1_breakdown_prompt_attach_a_pinterest_photo.txt). Use the response as trait notes only. The source photos are third-party references and are not included here.
2. In separate **text-only** chats, run [her character prompt](prompts/2_her_character_prompt_text_only.txt), [his character prompt](prompts/3_him_character_prompt_text_only.txt), and [the car prompt](prompts/4_car_prompt_text_only.txt). Do not attach the Pinterest photos to these chats.
3. Attach each generated character in a fresh chat and run [the six-angle prompt](prompts/5_six_angle_sheet_prompt_attach_the_character.txt). The prompt was run once for her and once for him.
4. Attach the generated car and run [the side-profile prompt](prompts/6_car_side_profile_prompt_attach_the_car.txt), then [the rear-view prompt](prompts/7_car_rear_prompt_attach_the_car.txt).
5. Attach her, him, and the car, in that order, and run [the timed storyboard prompt](prompts/8_storyboard_prompt_attach_her_him_car.txt). Check the speed tags and continuity before using a board as a video reference.
6. In Seedance 2.5 omni-reference, choose **20 seconds, 9:16, 720p, audio on**. Attach **Image 1: her; 2: her six-angle sheet; 3: him; 4: car; 5: storyboard**. Run [the exact video prompt](prompts/9_video_prompt_seedance_2_5_attach_5_images.txt).
7. Edit the generated clip. In this run, the slow portion began about a second early, and the cut back to real speed landed three frames before the wheels touched. The edit placed the impact sound on the wheels, with music driving into the jump, dropping in the air, and returning on the landing.

This run used one Seedance take and no retries. Its timing and appearance are observations from this clip, not guarantees for another generation.
